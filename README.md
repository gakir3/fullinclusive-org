# 一般社団法人フルインクルーシブ機構

## 1. 設立の意図（はじめに）
本法人は、不登校や障害をはじめとする様々な理由により、現代の社会構造の中で困難や生きづらさを抱える子どもや若者、そしてその保護者・家族を包括的に支援することを目指して設立された一般社団法人です。

私たちが強く問題意識を持っているのは、困難を抱える本人だけでなく、そのケアの負担を個人の責任として強制的に背負わされてしまっている家族全体の孤立です。誰一人として学校や地域から排除されず、それぞれのやりがいを持って自分自身の人生を損なわずに生きられる社会の実現を目指します。

また、私たちは現場での「実践」と、教育学や社会学などの「学術研究」が分断されることなく、常に双方向を行き来（往還）する仕組みを重視しています。エビデンス（証拠）に基づく実践と研究を通じて、生きづらさを生み出している社会構造そのものの変容を促していくことが、私たちの大きな目標です。

公式ウェブサイト：[fullinclusive.org](https://fullinclusive.org)

## 2. 定款の概要（事業目的と活動内容）
当法人は、上記の目的を達成するため、主に以下の事業を展開します。

* **当事者の声に基づく社会実装とプラットフォーム運営**
  生きづらさを抱える当事者や家族一人一人のナラティブ（語り）に立脚し、教育・福祉・労働領域の社会課題を抽出します。地域の支援情報を社会資源として統合・媒介するプラットフォームをデザイン・開発し、社会に実装します。
* **学術研究・政策提言と技術の活用**
  多様な学問分野の知見を融合した調査研究、実証実験、エビデンスに基づく政策提言を行います。また、大規模言語モデル（LLM）をはじめとする次世代型支援システムを構築し、知見の分析や研究への二次利用を進めます。
* **ネットワーク構築と知見の社会還元**
  公民学の連携を促進し、国内外の専門家とのネットワークを構築します。得られた知見はデジタルコンテンツや書籍、ワークショップなどを通じて広く社会へ還元・普及啓発を行います。
* **公的研究費の管理と研究倫理の徹底**
  文部科学省のガイドラインに準拠した適正な運営・監査体制（内部統制システム）を整備し、高い研究倫理と行動規範のもとで実証・研究活動を遂行します。

## 3. このリポジトリについて
本リポジトリでは、一般社団法人としての活動基盤となるWebサイトの管理や、社会資源情報を統合するための情報プラットフォーム（システム）の構築・開発に関するドキュメントや関連データを管理しています。
